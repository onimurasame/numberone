Answer

examples/advanced-hash-chain-time-travel/run.mjs exercises Number One's core storage and verification invariants end to end — proving linear-time secret scrubbing, content-addressed blob storage, deterministic snapshotDigest replay, and fail-closed 1-byte tamper detection inside an interactive Three.js 3D Hash-Chain Helix.

  1. StreamStore.append() scrubs synthetic GitHub PAT & AWS key patterns in O(n) linear time before SHA-256 hashing (0 raw tokens leaked).1
  2. Oversized crash traces are stored once by SHA-256 content digest (n1://fallback/<sha256>) and cross-checked on verify.2
  3. AuthorityEngine.arbitrate() distinguishes negated compliance from real affirmative violations via extractAffirmativeClauses.3
  4. Cloning .numberone/ and mutating 1 byte at seq #4 immediately fails StreamStore.verifyIntegrity() (fail-closed).4
